# 48-Hour Setup Checklist — Public-Facing (Task A5, artifact 3)

*This checklist backs the "live in 48 hours" promise. Publish only after owner approval (it becomes a commitment).*

## Day 0–4h — Kickoff (client call, 30 min)

- [ ] Practice name, address, main number, after-hours number/forwarding target
- [ ] Hours + holiday schedule
- [ ] Services list (plain-language patient-facing names)
- [ ] FAQ answers: parking, insurance categories accepted (client-supplied, we never advise), new-patient flow
- [ ] Scheduling link/calendar method (Calendly / Google Calendar / practice software booking URL)
- [ ] Escalation rules: when to offer immediate human callback (client-defined)
- [ ] SMS + email recipients for lead capture (owner + front desk)

## Day 4–24h — Build

- [ ] Conversation flow configured (greeting → intent → FAQ/booking → handoff)
- [ ] Confirm-and-repeat protocol enabled for names/addresses (complaint T7)
- [ ] Human-handoff button tested (complaint T2): "talk to a person" → callback ≤15 min business hours
- [ ] Booking integration tested with test appointment (then removed)
- [ ] Lead capture SMS + email tested end-to-end (complaint T3: every lead has an owner)
- [ ] Call recording policy set per client consent requirements

## Day 24–48h — Go live

- [ ] Forward after-hours/overflow number → AI line
- [ ] 10 test calls (in-hours simulation): booking, FAQ, off-script → callback offer, angry caller → immediate handoff
- [ ] Client test call with owner on the line — sign-off
- [ ] Reporting dashboard active; first weekly report scheduled
- [ ] Docs handed over: who to call, how to change hours/FAQs

## Post-live (Day 3–7)

- [ ] Review first 20 real calls with client: tune phrases, addresses, FAQ gaps
- [ ] Confirm zero missed-human-handoff requests
- [ ] Check-in email: metrics + 1 adjustment round included

**Total client effort: ~90 minutes across 2 days.**
